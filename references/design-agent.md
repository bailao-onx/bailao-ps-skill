# Refining a design in Photoshop

Use this when the user asks for a stronger design rather than a strict recreation. Inspect at full size and the final viewing size. Identify the main message, first attention point, spacing, contrast, type hierarchy, and lighting. State the visual problem clearly; choose a small set of changes that fixes it.

Preserve confirmed copy, prices, claims, logos, and product identity. Create a new task-owned PSD version so the original remains available. Use Photoshop's native type, shapes, masks, adjustments, Smart Objects, filters, and layer styles as needed. A technique belongs in a reusable script only after it has been tested in Photoshop and checked in a reopened PSD.

Export from the reopened file and compare it with the prior version at full size and as a social thumbnail. Remove effects that weaken legibility or hierarchy. Report the actual changes and any approximations.
